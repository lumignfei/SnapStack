# 图片标记、紧凑托盘与固定签名检查

2026-10-10。当前源码 0.2.0，尚未发布对应新安装包。

## 实现

- 工具栏 320×56 pt，去掉拖动柄；按钮外空白区域支持拖动，保留收起、展开动画。
- 图片托盘与工具栏等宽，保留白色小三角；点击图片放大、添加备注，拖动排序。
- 大图限制在左侧画布内等比例显示，右侧放备注和标记工具。
- 备注按实际侧栏宽度计算换行高度，上限后内部滚动。Return 完成，Shift+Return 换行；没有“随内容增高”提示。
- 矩形、圆圈、箭头、画笔、文字、马赛克；五种颜色、三种粗细、撤销/重做。
- 标记、备注和撤销历史绑定图片 UUID；粘贴按原像素尺寸生成带标记图片，原图在当前会话内不被覆盖。
- 本机构建沿用固定自签名证书；证书与私钥不在仓库中。公开下载历史包仍为 ad-hoc 签名，未进行 Developer ID 签名或公证。

## 已验证

- release 编译、Info.plist、严格签名校验通过。
- 窄侧栏备注高度、Return/Shift+Return/输入法行为测试通过。
- 六种标记导出、撤销重做、原图字节不变、导出像素尺寸、排序后备注与标记对应关系测试通过。
- 原生 SwiftUI/AppKit 渲染检查：长备注达到上限时，画布和工具区没有越界；横图、竖图、超宽图固定边界测试通过。
- 正式应用更新、退出重开；两项权限继续显示“已授权”。固定身份建立后，连续两次代码更新保留了本机权限。

## 尚未验证

当前版本在 ChatGPT、微信等目标应用中的完整真实截图、画图、批量图文粘贴流程未专项验收。导出测试不等于交互全部通过。未测量动画帧率；Intel、macOS 13.5、多屏、Space 与全屏场景未专项实机验证。

图片、标记和备注仅在当前会话存在，正常退出会清空。
