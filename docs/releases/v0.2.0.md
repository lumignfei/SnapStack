# SnapStack 0.2.0 · 源码更新

2026-10-10。此版本目前仅更新源码，尚未发布对应安装包；旧 v0.1.2 下载包不包含以下功能。

- 320×56 pt 冷灰蓝悬浮栏、同宽图片托盘；去掉拖动柄，按钮外留白支持拖动，保留展开与收起动效。
- 点击缩略图放大查看；左侧图片严格限制边界，右侧备注随内容增高到上限。
- 图片标记：矩形、圆圈、箭头、画笔、文字和马赛克；颜色、粗细、撤销与重做。原图保留，粘贴输出标记后的图片。
- 本机构建沿用固定自签名身份，缺少身份时停止构建，不再静默改用临时签名。
- 截图改为 Control + Shift + A，粘贴全部改为 Control + Shift + S。
- 可选图片备注，按图片 UUID 绑定；拖动重排后备注跟随原图。Return 收起，Shift + Return 换行，兼容输入法选字。
- 图片和备注分别按当前顺序粘贴；减少备注文字的首尾空行。
- 修正弹出面板尺寸、截图按钮点击区域与悬停反馈。
- 新叠片取景框图标、权限引导和启动策略检查。

## 验证与限制

构建和验证范围见 [图标与功能检查](../icon-release-checks.md)。ChatGPT、微信等接收应用的完整图文流程尚未专项验收；没有动画帧率测量。首次切换签名身份需要重新授权，本机后续两次代码更新已经保留授权。退出会清空截图和备注。
