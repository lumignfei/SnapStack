# SnapStack / 连截 v0.1.1 · 快捷键更新

区域截图快捷键改为 **⌃⇧S（Control + Shift + S）**，替代 v0.1.0 的 ⌃⌥⌘S。菜单、悬浮栏提示和使用文档已同步更新。

## 下载与使用

下载 Assets 中的 **SnapStack-0.1.1-macOS-universal.zip**，解压后将 SnapStack.app 放进“应用程序”。支持 Apple Silicon 与 Intel 架构，要求 macOS 13.5 或更新；Intel 与最低系统版本尚未实机验证。

先启动应用，再按 ⌃⇧S 连续截取区域。整理缩略图顺序后，点击目标应用的输入位置，确认目标名称，点击一次“全部粘贴”。每张发送后仍等待 400ms。

## 升级与权限

本版采用 ad-hoc 签名，尚未 Apple Developer ID 签名或公证。首次打开可能需要按 [Apple 官方说明](https://support.apple.com/en-us/102445)在“隐私与安全性”中允许打开。

新版签名可能使旧授权失效。截图需要屏幕录制，自动粘贴需要辅助功能；必要时退出应用，从这两个权限列表移除旧 SnapStack，再添加当前安装的版本，并重新打开。

连续截图、临时队列、删除、拖动排序、逐张粘贴和清空功能保持原有行为。飞书等接收应用尚未专项验证，固定等待不能保证接收完成。完整说明见 [README](https://github.com/lumignfei/SnapStack#readme)。MIT License。
