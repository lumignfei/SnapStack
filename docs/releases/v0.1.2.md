# SnapStack / 连截 v0.1.2 · 悬浮栏收起／展开

启动后显示一个可拖动的小悬浮按钮，点击展开截图栏。右上角向下箭头和菜单栏“连截”均可收起／展开，收起时角标显示截图张数，队列、排序和粘贴目标保留。

截图期间悬浮窗口暂时隐藏；成功后自动展开，按 Esc 取消后恢复截图前的状态。清空队列或删除最后一张后自动收起。权限或截图错误会展开并显示提示。

## 下载与使用

下载 Assets 中的 **SnapStack-0.1.2-macOS-universal.zip**，解压后将 SnapStack.app 放进“应用程序”。支持 Apple Silicon 与 Intel 架构，要求 macOS 13.5 或更新；Intel 与最低系统版本尚未实机验证。

区域截图快捷键仍为 **⌃⇧S（Control + Shift + S）**。点击一次“全部粘贴”，按当前队列顺序逐张粘贴，每张发送后等待 **400ms**，完成后队列保留。

## 验证与升级

已在 Apple Silicon Mac 实测：小按钮点击与拖动、菜单栏切换、连续截图、两种状态下取消后恢复、收起后队列与排序保留、单张删除、删除最后一张及清空后自动收起。使用文本编辑 RTFD 文档验证了 B → A 的逐张粘贴顺序及粘贴后状态保留。飞书等其他接收应用尚未专项验证。

本版采用 ad-hoc 签名，尚未 Apple Developer ID 签名或公证。首次打开可能需要按 [Apple 官方说明](https://support.apple.com/en-us/102445)在“隐私与安全性”中允许打开。

升级前请先完成当前队列的粘贴或处理；临时队列不会跨应用重启保留。新版签名可能使旧授权失效，必要时退出应用，从屏幕录制及辅助功能权限列表移除旧 SnapStack，再添加当前安装的版本，并重新打开。
