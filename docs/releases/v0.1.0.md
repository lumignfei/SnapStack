# SnapStack / 连截 v0.1.0 · 首个预览版

连续截取多个区域，先放进悬浮截图栏，整理顺序后点击一次“全部粘贴”。

## 下载

下载下方 Assets 中的 **SnapStack-0.1.0-macOS-universal.zip**，解压后将 SnapStack.app 放入“应用程序”，双击启动。包含 Apple Silicon 和 Intel 架构，要求 macOS 13.5 或更新；实机验证使用 Apple Silicon，Intel 与最低系统版本尚未实测。

`Source code` 是源码，并非安装包。`SHA256SUMS.txt` 提供 ZIP 的 SHA-256 校验值。

## 功能

- 全局区域截图：⌃⌥⌘S，支持连续收集。
- 悬浮栏横向缩略图、单张删除和拖动排序。
- 一键逐张粘贴，按当前队列顺序发送 Command-V，每张发送后等待 400ms。
- 清空临时队列，菜单栏入口与退出按钮。

## 首次打开与权限

本版采用 ad-hoc 签名，尚无 Apple Developer ID 签名和公证。首次打开可能被 macOS 阻止；仅在信任本项目时，按 [Apple 官方说明](https://support.apple.com/en-us/102445)在“系统设置 → 隐私与安全性”中允许打开。

截图需要屏幕录制权限，自动粘贴需要辅助功能权限。按系统提示退出并重新打开。若权限开关已开但仍无法使用，可移除旧记录并重新添加当前应用。

## 使用与已知限制

先启动应用，再按快捷键；快捷键无法启动已退出的应用。粘贴前点击目标输入位置，确认悬浮栏底部的目标名称，点击“全部粘贴”并等待完成。

已通过本地文本编辑 RTFD 文档实测，包括连续截图、删除、拖动重排后按 C/A 顺序粘贴和清空。飞书等其他接收应用尚未专项验证，固定等待可能无法适应慢速上传或弹窗，请核对实际收到的图片数量。

队列在粘贴后保留，清空或正常退出会删除临时截图；没有历史恢复。粘贴覆盖系统剪贴板并保留最后一张图。应用不会自动按 Enter 发送消息，没有联网和上传功能。
