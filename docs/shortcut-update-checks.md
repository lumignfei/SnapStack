# 快捷键更新验证 · 2026-10-09

当前正式应用 `dist/SnapStack.app` 已更新：Control + Shift + A 截图，Control + Shift + S 粘贴全部。菜单、按钮悬停提示、空队列及截图状态提示和 README 已同步。两组快捷键独立注册，单组失败不会撤销另一组；报错说明对应组合键。粘贴等待修饰键释放后再发送 Command-V，持续按住超过两秒则停止并保留队列。

验证结果：
- release 构建、Info.plist 检查及代码签名检查通过。
- 退出旧版后，用正式快捷键服务代码运行注册检查：A/S 同时注册、重复占用拒绝、各自释放并重新注册均通过。检查不模拟按键，结束释放快捷键。
- 当前正式应用已打开，界面显示新组合键，未出现注册失败消息。
- 更新签名对应的原有系统授权记录后，应用内屏幕录制与辅助功能均显示“已授权”。
