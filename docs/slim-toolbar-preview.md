## 保留动效的性能修复

用户明确要求保留收起/展开和浮窗弹出动效；不能以取消动效替代掉帧修复。此前瞬间改变尺寸的版本已替换。

- 长条与悬浮按钮各自保持一个固定尺寸的布局，队列或粘贴状态改变后，在空闲时刷新缓存。260 ms 连续形变由 Core Animation 的轮廓路径、遮罩和阴影完成；文字图标错开淡出/淡入，避免重叠，不在动画每帧重新排版。
- 过渡窗口覆盖起止位置；结束后恢复真实交互窗口。全局截图可中止过渡并先恢复终态，再隐藏窗口。原有右下锚点和屏幕约束保留。
- 图片和更多浮窗复用宿主，隐藏时预布局。自定义透明 NSPanel 使用同一个白色形状绘制主体和尖角，消除原生材质尖角与白色内容的色差。弹出采用 200 ms 的缩放、位移与淡入，收起 130 ms，保留运动；工具栏锚点移出窗口时同步关闭浮窗，避免残留。
- 遵守系统减少动态效果设置。
- 本轮实测长条启动准备从 61.39/95.26 ms 降为 1.27/2.53 ms。这是应用侧启动准备耗时，不是显示帧率，不证明全程零掉帧。原始开发预览日志位于 `/tmp/snapstack-motion-preview.log`。
- 已验证收起/展开终态、五张图片浮窗重复开关、更多与图片面板互斥、清空后空队列浮窗。正式应用仍未覆盖，授权未改动。
