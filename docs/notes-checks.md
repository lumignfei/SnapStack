# 可选备注 · 2026-10-09

用户确认后已更新 `dist/SnapStack.app` 并重新打开，当前为带可选备注功能的正式本地构建。旧应用由构建脚本备份在 `.build/previous-app/SnapStack.app`。

## 行为

- 默认仅显示缩略图；每张有“添加备注”，选择后只展开该图备注。“收起”保留文字，重新展开可编辑。
- 备注存于 ScreenshotItem，按 UUID 绑定；排序后备注跟随原图，图片编号按当前顺序计算。删除/清空会移除相应备注。
- 保存范围与截图队列一致：当前运行会话，退出后清空，不是跨重启永久保存。
- 原生 NSTextView 使用同一字形布局绘制占位符；拼音组词时不绘制占位符，也不从 SwiftUI 覆盖输入法正在组词的内容。粘贴及关闭浮窗前提交当前输入。
- 每张先粘贴图片；仅非空备注再以独立纯文本粘贴“图片 N：备注”，支持多行。空白备注跳过，不发送 Enter。
- 备注展开时按内容尺寸调整浮窗，白色尖角保留。现有收起/展开及浮窗动画保留；输入文字不会反复重建工具栏图像缓存。

## 2026-10-10 回车收起与换序反馈

无输入法组词时 Return/小键盘 Enter 提交当前文本并收起；Shift+Return 明确插入换行，组词期间交给输入法。原生 NSTextView 回归覆盖提交、不添加换行、Shift 换行和 marked text 不误提交。两张图分别绑定备注，反复交换四次，检查 UUID、备注内容及编辑目标均保留；原有排序后的粘贴编号检查通过。

队列与工具条缩略图位置使用 240ms easeInOut，移动图片描边保留 850ms；拖动命中处理间隔 260ms 避免过渡期间重复交换，拖动开始先提交当前编辑。动画时长是实现参数，未做帧率测量。release 与签名通过，按用户授权清空重启，刷新原有两项权限。未创建额外预览应用。
