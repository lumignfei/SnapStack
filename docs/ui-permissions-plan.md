# 连截 UI 与首次授权更新

目标：为个人账号首条视频准备一版清楚、轻巧、可实际使用的截图工具。

本轮参照 DogSC 的浅色面板、留白和授权流程，继续使用 SnapStack 的原生实现。

1. 悬浮栏：采用用户选定的 B「冷灰蓝」：冷白底、雾蓝主按钮、浅蓝状态；截图队列作为视觉中心，退出与权限放进更多菜单。
2. 首次使用：一页说明屏幕录制用于截图、辅助功能用于自动粘贴；屏幕授权完成后即可进入，辅助功能可稍后开启。
3. 设置衔接：跳转对应系统设置，展示带应用图标的拖拽提示条；提示条跟随设置窗口，返回应用自动检查权限。
4. 异常恢复：权限未生效时提供刷新、定位当前应用和重新打开应用的入口。
5. 验证：编译与签名检查、窗口显示与收展、权限页与设置跳转、截图队列和排序回归。系统授权由用户完成。

保留松手完成截图的操作。图片旁备注及图文粘贴为下一轮；移动选框、图片内标注、录屏与剪辑不属于本轮。

实现前的本地源码备份：`.build/design-baseline-20261009/source-before.tar.gz`。已有未提交的动画改动也单独保存在该目录。

- 已通过：Swift 编译、Info.plist 检查、应用签名验证、diff 格式检查；新图标已打入应用包。
- 已实际检查：授权页布局、空队列悬浮栏、收起后展开、关闭引导返回浮窗、缺少截图权限时打开引导、跳转屏幕录制设置、授权恢复菜单。
